Coordinates are real pixels rather than a viewBox: a viewBox stretched to the container would stretch the stroke with it. Everything that repeats is positioned HTML rather than SVG. A template element parsed inside SVG lands in the SVG namespace, where it is an ordinary unknown element with no content property, and x-for over it silently renders exactly one item. Only the continuous strokes are SVG, and each of those is a single path with nothing to repeat. {% endcomment %}
